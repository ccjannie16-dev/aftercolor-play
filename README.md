# Aftercolor

A quiet narrative game about memory, care, and the color left behind in a home.

## Controls

- Click or tap the pale markers to explore.
- Use the on-screen buttons for dialogue choices and mini-games.
- Press `Enter` or `Space` to advance dialogue; use `Skip` to jump to the next choice or the end of a sequence.
- Open the top-left menu to save, replay unlocked moments, adjust settings, or return to the title screen.
